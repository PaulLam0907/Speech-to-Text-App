## Installation
1. Clone the repository :
```bash
git clone https://github.com/PaulLam0907/speech-to-text-app.git
```

2. Install dependencies :
- streamlit
- openai-whisper
- ffmpeg on system's PATH variable (optional)

## Usage
To launch the `.exe` app, only download the `build` folder and run the `SpeechToTextApp.exe` on Windows  


Alternatively, using the `app.py` module, in the terminal at the root folder :  
```
streamlit run app.py
```  
Or run `main.py` directly 
```
python main.py
```
